# pgvector 扩展安装指南

## 问题描述

在使用 Django 项目时，出现以下错误：

```
django.db.utils.ProgrammingError: type "vector" does not exist
LINE 1: ...KEY GENERATED BY DEFAULT AS IDENTITY, "embedding" vector(102...
```

这是因为 PostgreSQL 数据库缺少 `pgvector` 扩展，无法创建 `vector` 类型的字段用于存储向量嵌入数据。

## 修复步骤

### 1. 安装 pgvector Python 包

```bash
pip install pgvector
```

### 2. 连接 PostgreSQL 数据库

使用 Python 脚本连接远程数据库并安装扩展：

```python
from dotenv import load_dotenv
import os
import psycopg

load_dotenv()

conn = psycopg.connect(
    host=os.getenv('PG_DB_HOST'),
    port=os.getenv('PG_DB_PORT'),
    dbname=os.getenv('PG_DB_DATABASE'),
    user=os.getenv('PG_DB_USER'),
    password=os.getenv('PG_DB_PASSWORD'),
    sslmode='prefer'
)
conn.autocommit = True
cur = conn.cursor()

cur.execute('CREATE EXTENSION IF NOT EXISTS vector;')
print('pgvector extension created successfully')

cur.close()
conn.close()
```

### 3. 运行 Django 迁移

```bash
python manage.py migrate
```

## 验证方法

检查 pgvector 扩展是否安装成功：

```python
import psycopg

conn = psycopg.connect(...)
cur = conn.cursor()
cur.execute("SELECT extname FROM pg_extension WHERE extname = 'vector';")
result = cur.fetchone()
if result:
    print('pgvector extension installed:', result[0])
else:
    print('pgvector extension NOT installed')
```

## 注意事项

1. **数据库版本要求**：pgvector 需要 PostgreSQL 11+
2. **权限要求**：连接数据库的用户需要有创建扩展的权限（通常是 superuser）
3. **SSL 模式**：生产环境建议使用 `sslmode='require'`
